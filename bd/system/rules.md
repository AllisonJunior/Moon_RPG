# Regras Gerais

- Todas as rolagens principais desse sistema como de costume são feitas utilizando um d10.
- O combate é dividido em Cenas e Turnos, cenas se tratam da rotação de todos os turnos de um combate e o turno é a ação nessa cena de um personagem.
- A ordem dos turnos é definida pela Speed de cada personagem que é rolada novamente todo início de cena.
- Shield se trata de uma vida extra que um personagem possui e por padrão essa vida extra é removida todo fim de cena.
- Um acerto crítico causa dano máximo.
- Nesse sistema existem três tipos de dano base: Cortante, Perfurante e Esmagante; Consequentemente cada personagem também possui diferentes resistências a esses danos: Imune, Resistente, Normal e Vulnerável.
- Cada personagem possui quatro atributos únicos com cada personagem possuindo um atributo preferido.
- Quando um personagem tem seus pontos de vida reduzidos a 0 o mesmo entra no estado desestabilizado.
- Por padrão efeitos funcionam no sentido de Potency (Quantidade), as vezes até mesmo referenciados como 'X' ou 'Stack', mas, existem efeitos que possuem Count (Duração) comumente referenciados com 'Y', que por padrão se tratam de condicionais de redução do efeito.
- Todos os personagens possuem um recurso chamado Moon Points que é utilizado para utilizar Skills.
- Algumas criaturas possuem sanidade, que afeta diretamente o funcionamento de Skills durante o combate.
